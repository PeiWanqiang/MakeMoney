# 体验用经典策略语料

用途：在网页版逐条粘贴到「第 1 步 · 说出策略」，体验完整的四步流程（说出 → 确认 → 回测 → 优化）。

每条都按 `ready` 的门槛写全了五件事：**周期、入场条件、方向、仓位、止损**，再加一个明确的离场条件。缺任何一项，模型会走 `needs_clarification`。

能力边界（写策略时别越界）：指标只有 SMA / EMA / RSI / MACD / ATR / 布林带 / N 根最高最低 / 涨跌幅 + 四则运算；周期只有 1m / 15m / 1h / 4h / 1d / 1w（日线与周线按 UTC 开盘，周线自周一开始）；仓位只有固定金额、权益百分比、风险百分比；止损只有百分比；止盈只有风险回报倍数。

数据可用性：本地已缓存 **BTCUSDT 永续 15m/1h/4h（2020-01 ~ 2026-07）**。ETHUSDT / SOLUSDT 走远程拉取，会明显更慢。下面的建议区间都基于 BTCUSDT + Binance Perpetual。

单次回测上限 10000 根 K 线，换算下来：1h 最长约 400 天、4h 最长约 4.5 年、15m 最长约 100 天。**1h 周期不要点「最近 3 年」预设，会直接报超限。**

---

## 一、趋势跟随

### 1. 双均线金叉死叉（最经典的一条）

```
在1小时K线上，当20周期EMA上穿50周期EMA且当前空仓时做多BTC，单笔风险为账户权益的1%，止损5%；当20周期EMA下穿50周期EMA时平仓。
```

- 建议：BTCUSDT / Binance Perpetual / 最近 1 年
- 看点：`crossAbove` 是真正的"交叉事件"而不是"大于"，确认页应该显示"上穿"而不是"高于"。

### 2. 唐奇安通道突破（海龟法则简化版）

```
在4小时K线上，当收盘价高于前20根K线的最高价且当前空仓时买入开多，用账户权益的20%作为仓位，止损8%；当收盘价低于前10根K线的最低价时平仓。
```

- 建议：BTCUSDT / Binance Perpetual / 最近 3 年
- 看点：`highest("high",20,1)` 的 lag 必须是 1（不含当根），否则永远突破不了自己。确认页写的是"最近 20 根的最高价（1 根之前）"才对。

### 3. MACD 柱状值转正

```
在4小时K线上，当MACD(12,26,9)的柱状值由负转正且当前空仓时做多，每次固定用2000 USDT仓位，止损6%，止盈12%；柱状值转负时平仓。
```

- 建议：BTCUSDT / Binance Perpetual / 最近 3 年
- 看点：止盈 12% / 止损 6% 应该被折算成 `takeProfitRiskReward = 2`；同时试试它会不会把"由负转正"正确写成 `crossAbove(...histogram..., 0, 0)` 形态。

### 4. 均线之上顺势持有

```
在1小时K线上，当收盘价高于200周期EMA且RSI(14)高于55、当前空仓时做多BTC，单笔最多亏损账户的1.5%，止损4%；当收盘价跌破200周期EMA时平仓。
```

- 建议：BTCUSDT / Binance Perpetual / 最近 1 年
- 看点：200 周期 EMA 需要长预热，观察回测起始点是否被正确推后。

## 二、均值回归

### 5. RSI 超卖抄底（4 小时版）

```
在4小时K线上，当RSI(14)低于25且当前空仓时做多BTC，用账户权益的30%开仓，止损7%，止盈14%；RSI高于60时平仓。
```

- 建议：BTCUSDT / Binance Perpetual / 最近 3 年
- 看点：和首页自带的 1h 版本对照，同一套逻辑换周期后胜率/回撤怎么变。

### 6. 布林带下轨反弹

```
在1小时K线上，当收盘价低于布林带下轨（20周期，2倍标准差）且当前空仓时买入做多，单笔风险1%，止损5%；当收盘价回到布林带中轨上方时平仓。
```

- 建议：BTCUSDT / Binance Perpetual / 最近 1 年
- 看点：布林带三条轨在确认页会被翻译成中文轨名，检查上/中/下有没有对错位。

### 7. 连续下跌抄底

```
在15分钟K线上，当最近20根K线收盘价跌幅超过5%且当前空仓时做多BTC，用账户权益的25%开仓，止损3%，止盈6%；当最近10根K线涨幅超过3%时平仓。
```

- 建议：BTCUSDT / Binance Perpetual / 最近 2 个月
- 看点：`percentChange` 的正负号方向，"跌幅超过 5%"必须是 `< -0.05`。

## 三、突破与动量

### 8. 布林带上轨突破

```
在1小时K线上，当收盘价上穿布林带上轨（20周期，2倍标准差）且当前空仓时做多，用账户权益的20%开仓，止损4%，止盈8%；当收盘价跌回布林带中轨下方时平仓。
```

- 建议：BTCUSDT / Binance Perpetual / 最近 1 年
- 看点：和第 6 条是同一个指标的相反用法，很适合放在一起看"同指标反向逻辑"谁更能扛。

### 9. 20 根新高动量

```
在15分钟K线上，当收盘价创出前20根K线的新高且当前空仓时买入做多BTC，单笔风险为账户的1%，止损2.5%，止盈5%；持仓时如果收盘价跌破前10根K线的最低价则平仓。
```

- 建议：BTCUSDT / Binance Perpetual / 最近 2 个月
- 看点：短周期高频信号，交易笔数会明显变多，正好用来看手续费和滑点被吃掉多少。

### 10. 中期动量

```
在4小时K线上，当最近18根K线收盘价涨幅超过8%且当前空仓时做多BTC，用账户权益的25%开仓，止损10%；当最近18根K线涨幅回落到0以下时平仓。
```

- 建议：BTCUSDT / Binance Perpetual / 最近 3 年
- 看点：典型的"追涨"策略，观察它在 2022 那种下跌年份被反复打脸的样子。

## 四、做空与双向

### 11. RSI 超买做空

```
在1小时K线上，当RSI(14)高于75且当前空仓时做空BTC，单笔风险为账户的1%，止损4%，止盈8%；RSI低于50时平仓。
```

- 建议：BTCUSDT / Binance Perpetual / 最近 1 年
- 看点：唯一的纯空头样本，用来验证空单的盈亏方向、爆仓与杠杆约束有没有算反。

### 12. 死叉做空

```
在4小时K线上，当20周期EMA下穿60周期EMA且当前空仓时卖出开空BTC，用账户权益的20%开仓，止损6%；当20周期EMA上穿60周期EMA时平仓。
```

- 建议：BTCUSDT / Binance Perpetual / 最近 3 年
- 看点：和第 1 条正好镜像，两条一起跑能直观看出这几年多空不对称。

## 五、多周期共振

### 13. 大周期定方向、小周期找入场

```
在1小时K线上，当4小时周期的收盘价高于4小时周期的50周期EMA、同时1小时RSI(14)低于40且当前空仓时做多BTC，单笔风险1%，止损4%，止盈8%；当1小时RSI高于65或收盘价跌破1小时50周期EMA时平仓。
```

- 建议：BTCUSDT / Binance Perpetual / 最近 1 年
- 看点：这条会用到 `timeframe("4h").` 前缀，是整套语法里最容易出未来函数的地方——重点看回测里的成交时间戳有没有早于 4h K 线收盘。

## 六、故意越界的样本（测边界诚实度）

这几条不是用来赚钱的，是用来看产品会不会硬编、会不会拿相似指标糊弄你。

### B1. 缺条件 → 应该追问

```
BTC 破位就进场，走弱就出来，仓位别太重，用小时线看。
```

期望：`needs_clarification`，逐条问"破位是指跌破什么"、"仓位具体多少"、"止损放哪"。

### B2. ATR 止损 → 支持指标但不支持这种止损形式

```
在4小时K线上，当收盘价高于前20根K线最高价时做多BTC，单笔风险1%，止损设在入场价下方2倍ATR(14)的位置；当收盘价跌破前10根最低价时平仓。
```

期望：要么说明止损只支持百分比（`unsupported` 或在 `assumptions` 里讲清换算），**不应该**默默改成一个百分比数字还不告诉你。这是海龟法则的原版止损，也是最值得盯的一条。

### B3. 资金费率 → 已知的前后不一致

```
在1小时K线上，当资金费率为负且20周期EMA上穿50周期EMA、当前空仓时做多BTC，单笔风险1%，止损5%；EMA下穿时平仓。
```

期望：目前第 2 步很可能判成 `ready`（分析端的能力清单里写了资金费率），但第 3 步回测会直接报错"当前网页回测数据只包含 OHLCV"。见 [web/worker/backtest-api.ts:918](../web/worker/backtest-api.ts#L918)。**这是分析端与回测端的能力清单不一致，属于产品缺陷，不是策略写错了。**

### B4. 需要非行情数据 → 应该直说做不到

```
在1小时K线上，当推特上BTC相关讨论热度进入前10%且订单簿买盘厚度大于卖盘两倍时做多，单笔风险1%，止损5%，热度回落时平仓。
```

期望：`unsupported`，并且明确列出缺的是舆情数据和订单簿深度，而不是换成成交量凑合。

---

## 建议的体验顺序

1. 先跑 **第 1 条**（双均线）走通全流程，熟悉四步长什么样。
2. 再跑 **第 6 条 + 第 8 条**（布林带回归 vs 突破），看同一指标两种用法的差异。
3. 跑 **第 13 条**（多周期），这是最容易出问题的语法路径。
4. 最后依次跑 **B1 ~ B4**，这四条才是真正检验"诚实"这个卖点的地方。
5. 挑一条交易笔数多的（第 9 条）进第 4 步自动优化，看调参后的验证段是不是真的更好。
