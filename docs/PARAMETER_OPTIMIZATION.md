# 策略语义锁定下的参数优化实验室

状态：Stage 1 已实现，Stage 2/3 规划中  
最后更新：2026-07-31

## 1. 通用能力定义

平台可以从任意受支持的机器策略契约中发现可调数字槽位，在不改变交易周期、开平仓动作、多空方向、指标与行情字段、比较符、布尔结构和成交时序的前提下，构造有限个参数候选，并使用同一份不可变历史数据执行可审计的训练/验证实验。

该能力不以某个策略、标的、周期、语言或数字常量为边界。无法通过机器契约和确定性执行器表达的参数不会因为模型提示词而被标记为可优化。

## 2. Stage 1 已实现

### 参数契约

- 条件表达式数字参数：指标周期、比较阈值和受限算术常量。
- 决策参数：仓位数值、止损比例和止盈风险回报比。
- 指标 lag/offset 默认锁定，避免无意改变时间引用和未来数据边界。
- 每个参数具有稳定 ID、原始值、数值类型、单位、建议范围和硬安全边界。
- 一次最多选择 4 个参数，每个参数 2～7 个取值点，单轮最多 16 个候选。

### 语义锁

服务端根据原始契约生成结构骨架，将允许变化的数字槽位替换为占位符并计算 SHA-256 指纹。浏览器不能提交修改后的契约，只能提交参数 ID 和范围。每个候选都由服务端从原始契约生成、重新执行契约校验，并再次比较结构指纹。

### 实验和缓存

- 同一实验只加载一次 K 线数据；不为每个候选请求外部行情。
- 历史数据读取顺序为本地静态库、热缓存、R2 持久缓存、官方归档冷启动和 REST 最后兜底。
- 参数候选按确定性网格生成；组合数超出预算时按固定位置采样。
- 时间顺序前 70% 为训练区间，后 30% 为验证区间；两个区间分别预热指标。
- 实验缓存键包含契约、语义锁、参数范围、目标、试验预算、回测配置、K 线摘要和实验版本。
- 完整实验收据写入 D1，计算结果写入 R2，并使用进程内热缓存消除同实例重复执行。

### 结果解释

当前支持稳健综合、收益优先和回撤优先三种确定性评分。胜率仅作为辅助指标，不能单独决定推荐。低交易样本、训练/验证差异和验证回撤会产生惩罚。

结果展示：

- 原始参数与推荐候选对比；
- 训练和验证收益、回撤、Sharpe、胜率、Profit Factor 和交易数；
- 验证收益—回撤散点图和 Pareto 前沿；
- 完整候选排名、实验数据来源、缓存状态、时间切分和语义锁哈希。

如果候选没有超过通用改进门槛，系统明确保留原始参数，不强行推荐一个变化版本。

## 3. 当前真实边界

- 70/30 验证不是最终盲测；Stage 1 推荐只能称为研究候选。
- 验证区间当前独立预热指标，尚未实现带训练尾部上下文但不计入验证绩效的 warm-up 窗口。
- 尚未实现 walk-forward、参数邻域稳定性、手续费/滑点压力测试、不同市场状态分层和多重选择偏差修正。
- 尚未将候选自动升级为正式不可变策略版本；这是刻意的产品门禁。
- AI 尚未参与参数范围设计或结果解释。当前范围由通用确定性规则生成，数值搜索和回测完全不调用模型。
- 同步 Worker 适合有界小实验；大规模、多用户实验需要异步任务队列、并发配额、取消、重试和进度持久化。

## 4. 后续阶段

### Stage 2：稳健性门禁

1. 指标 warm-up 与绩效窗口分离。
2. Anchored/Rolling walk-forward。
3. 最终盲测窗口只使用一次。
4. 参数邻域稳定性热图。
5. 手续费、滑点和延迟压力测试。
6. 牛熊、横盘和高波动分层。
7. 多重尝试披露和 Deflated Sharpe 等选择偏差指标。
8. 通过门禁后由用户确认生成新的不可变策略版本。

### Stage 3：AI 实验研究员

AI 只能：解释参数、建议有界范围、提出下一轮实验、阅读证据和说明脆弱性。AI 不能直接改写回测结果、扩大安全边界、读取最终盲测后继续拟合，或把策略结构变化伪装成参数优化。任何指标、规则或动作变化必须创建显式策略分支并由用户确认。

## 5. 泛化验收证据

- 原始回归：算术回撤比例和账户权益仓位继续由完整回测执行。
- 参数变体：比较阈值与止损比例可以同时进入有界实验。
- 结构变体：RSI 周期和阈值能被发现，lag=0 保持锁定。
- 边界拒绝：未知参数 ID 在实验执行前返回 400。
- 语义一致性：每个候选重新通过契约校验和结构指纹比较。
- 既有回归：Web 构建与全部自动测试继续通过。
